Architecture: 9 Decoupled Verifiable Components

1. TestCaseInput

Schema validation on inputs; restricts protocol to HTTP/HTTPS; registers secret tokens for log masking.

2. LLMPlanner

Emits structured JSON TestPlans adhering strictly to Pydantic schemas. Flags missing credentials instead of hallucinating logins.

3. PlanValidator

Pre-execution gate checking action allowlists, required parameters, and step limits (max 30).

4. BrowserExecutor

Coordinates Playwright execution, enforces timeouts, captures millisecond durations and failure screenshots.

5. SmartLocator

Prioritizes ARIA role, label, and test-ID. Halts with LocatorAmbiguityError if multiple elements match.

6. AssertionEngine

Strict verification of visibility, text equality, title, and URL. Never reports PASS on assertion failure.

7. ResultReporter

Produces structured JSON, standalone HTML with base64 screenshots, and formatted Rich terminal summaries.

8. ConfigManager

Centralized settings loading via Pydantic from .env and environment variables.

9. SecurityManager

Guarantees zero eval/exec, blocks disallowed schemes (file://, javascript:), and masks credentials.
